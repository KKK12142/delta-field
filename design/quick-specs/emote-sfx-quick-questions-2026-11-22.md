# Quick Design Spec: 이모트 · 효과음 · 선생님 창에서 바로 문제 내기

**Type**: New Small System (세 가지 묶음)
**Scope**: 3D 화면(src/three/)에만 넣는다. 2D(?view=2d)에는 넣지 않는다. 미니게임 3D는 다른 담당이 만들므로 미니게임 소리는 서버 상태 변화에 거는 함수만 둔다.
**Date**: 2026-11-22
**요청**: 교사 2026-11-22 밤 "이모트, 효과음, 바로 문제 내기까지 한 번에 다 진행해."(참고: OXplayground의 같은 기능)

## 1. 이모트

### 무엇을
학생·선생님이 8가지 이모트를 누르면 같은 맵에 있는 사람들 화면에서 내 캐릭터 머리 위에 말풍선이 1.5초 뜨고, 되는 것은 캐릭터 동작도 한다.

### 규칙
1. 이모트 8가지(shared/emotes.ts): 손인사(wave 동작), 꾸벅(몸 숙이기), 박수, 응원(jump), 춤(몸 흔들기), 점프(jump), 하트(도트 하트 그림), 웃음.
   말풍선은 이모지 대신 도트 그림(public/sprites/ui의 heart·sparkle 등)이나 도트 글꼴 글자("안녕!", "짝짝" 등)로 그린다.
2. 누르는 곳: 화면 아래 왼쪽 단추 줄(소리 단추 옆). 휴대폰은 "이모트" 단추 하나로 접혀 있고 누르면 펼친다. 키보드 1~8(글을 쓰는 중·창이 떠 있을 때는 받지 않는다).
3. 화면은 'emote' {id}를 보내고 바로 내 캐릭터에 보이지 않는다(서버가 받아 준 것만 보인다. 막힌 이모트가 나에게만 보이지 않게).
4. 서버(server/emotes.ts): 상태에 남기지 않는 한 번 메시지. 같은 맵에 있는 접속자에게만 보낸다.
   - 한 사람 재사용 대기 1.5초, 1분에 20번까지. 넘으면 버린다(답 없음).
   - 골든벨 문제를 푸는 중(phase 'question')에 골든벨 맵의 학생이 보낸 이모트는 보낸 학생과 선생님에게만 보낸다(남 따라가기 방지. 화면에서도 그때 흐려진 다른 학생의 말풍선은 그리지 않는다).
5. 말풍선은 1.5초 보이고 끝 0.3초 동안 흐려진다. 새 이모트가 오면 바꿔 그린다. 이모트가 뜰 때 "톡" 소리.

## 2. 효과음

### 무엇을
소리 파일 없이 WebAudio로 합성한다(src/audio/sfx.ts). 음색·길이·크기는 src/data/sfx.json.

### 규칙
1. 소리: 문제 시작, 마감 3초 째깍(3·2·1), 정답(맞음)·틀림·탈락·부활, 결과 팡파르, 공지, 이모트 톡, 미니게임 시작·줍기·맞음.
2. 거는 곳(src/audio/gameSounds.ts, 서버 상태를 0.1초마다 보고 바뀐 것에만 소리):
   - 골든벨 단계가 question으로(문제 번호가 바뀜) → 문제 시작. question 중 남은 시간 3·2·1 → 째깍.
   - reveal로 → 내 결과(correct·heart 맞음, wrong 틀림, out 탈락, revived 부활). 선생님·결과 없음은 맞음보다 작은 "공개" 소리.
   - end로 → 팡파르. 공지·강당으로 모으기 시작 → 공지 소리.
   - 미니게임: count·play로 → 시작, 내 miniScore가 오름 → 줍기, 내 miniOut이 켜짐 → 맞음, result로 → 팡파르. (미니게임 3D 화면이 없어도 상태만 보고 울린다.)
3. 소리 켜기/끄기 단추: 화면 아래 왼쪽(이모트 줄의 맨 앞). 기억은 localStorage(df-sound, try/catch). 처음은 켜짐.
4. 브라우저 정책: 첫 터치·클릭·키 누름 뒤에 AudioContext를 만들거나 깨운다. 그 전의 소리는 내지 않는다.

## 3. 선생님 창에서 바로 문제 내기

### 무엇을
선생님이 문제 파일 없이 골든벨 문제를 그 자리에서 쓰거나 붙여 넣어 낸다. 서버는 그 방의 메모리에만 두고 지금 골든벨 흐름을 그대로 쓴다.

### 규칙
1. 강당으로 모으기에서 문제 파일 목록 맨 위에 "바로 내기(직접 쓰기·붙여넣기)". 문제 파일이 없어도 고를 수 있다.
2. 바로 내기 창(src/ui/quickQuestions.ts):
   - 제목, 한 문제씩 쓰기(종류 OX·객관식 4지·단답형, 문제, 정답, 해설, 제한 시간 3~600초, 기본 20초), 여러 줄 붙여넣기, 지금 목록(지우기), "내 문제"(이 브라우저에 저장한 묶음 불러오기·지우기).
   - 붙여넣기 한 줄 형식(칸은 |로 나눈다. 해설은 없어도 된다. 끝 칸에 "30초"처럼 쓰면 그 문제의 제한 시간):
     - OX: `문제 | O | 해설`
     - 객관식: `문제 | 보기1 / 보기2 / 보기3 / 보기4 | 2 | 해설` (보기 2~4개, 정답은 보기 번호)
     - 단답형: `문제 | =답1, 답2 | 해설` (쉼표로 나눈 여러 표현 가운데 하나면 정답)
   - 형식이 틀린 줄이 하나라도 있으면 "3번째 줄: …" 목록을 보이고 하나도 더하지 않는다. 빈 줄은 건너뛴다.
   - "이 문제로 골든벨"을 누르면 서버에 보내고(gbQuickSet), 받아 주면 "내 문제"(localStorage df-quick-sets, 최근 20묶음)에 저장한 뒤 언제 모을지 고르는 단계로 간다.
3. 서버(server/quickQuestions.ts): 선생님만 보낼 수 있다. shared/quickQuestions.ts의 같은 규칙으로 다시 확인하고(문제 1~50개, 글 길이 상한), 방 메모리에 "바로 낸 문제" 한 묶음으로 둔다.
   파일 이름 자리에 '@quick'을 주면 이 묶음으로 골든벨을 시작한다. 넌센스는 없다(nonsense: false). 정답은 서버만 갖고 저장소·파일에 남기지 않는다.
4. 골든벨 진행 중 선생님 창의 "즉석 문제": 한 문제를 써서 내면(gbQuickAdd) 지금 문제 바로 뒤에 끼워 넣는다. 첫 문제 전·정답 공개 뒤면 바로 그 문제를 시작하고, 푸는 중이면 다음 문제로 둔다. 결과(end) 뒤에는 낼 수 없다.

## Tuning Knobs

| Knob | Default | 위치 |
|---|---|---|
| 이모트 재사용 대기 | 1500 ms | shared/emotes.ts EMOTE_COOLDOWN_MS |
| 이모트 1분 상한 | 20번 | shared/emotes.ts EMOTE_PER_MINUTE |
| 말풍선 보이는 시간·흐려짐 | 1500 / 300 ms | theme.ts emoteUi |
| 말풍선 색·크기 | — | theme.ts emoteUi |
| 소리 전체 크기·음색 | sfx.json | src/data/sfx.json |
| 바로 낸 문제 수 상한 | 50 | shared/quickQuestions.ts |
| 기본 제한 시간 | 20초 | shared/quickQuestions.ts |

## Acceptance Criteria

- [ ] 학생 A가 2를 누르면 같은 맵의 B 화면에서 A 머리 위에 말풍선이 뜨고, 다른 맵의 사람에게는 가지 않는다.
- [ ] 1.5초 안에 다시 누르면 서버가 버린다. 1분에 21번째는 버린다.
- [ ] 골든벨 문제 중에는 학생 이모트가 다른 학생에게 가지 않는다(선생님은 받는다).
- [ ] 소리 단추를 끄면 소리가 나지 않고, 새로 고쳐도 꺼진 채다. 첫 입력 전에는 AudioContext를 만들지 않는다.
- [ ] 붙여넣기 형식 세 가지가 문제가 되고, 틀린 줄은 줄 번호와 까닭이 보이며 더해지지 않는다.
- [ ] 바로 낸 문제로 강당 모으기 → 골든벨 문제·채점·단답형 맞춰 보기가 파일과 같게 돈다. 학생은 'gbQuickSet'을 보낼 수 없다.
- [ ] 즉석 문제가 지금 문제 뒤에 끼워져 total이 1 늘고, 정답 공개 뒤면 바로 시작한다.
- [ ] 회귀 없음: pnpm build, pnpm playtest(2D), pnpm playtest:gb3d, pnpm loadtest:3d 통과.
