# Delta Field 맵

맵 데이터의 형식과, 그림 담당이 그릴 바닥·벽·사물 종류를 적는다. 그림 규격(도트 16개 = 1칸, 3배)은 docs/art.md에 있다.

## 맵 파일
- src/data/school.json: 교실·복도·과학실·컴퓨터실·운동장(1부)과 수학실·도서관·계단·옥상 천문대(2부), 강당 입구가 이어진 학교 맵(id `school`). 방탈출을 한다.
- src/data/goldenbell.json: 골든벨 맵(id `goldenbell`).
- 형식은 src/data/room.ts에 있다. 좌표는 모두 칸 단위(한 칸 = 60px(타일 30도트 × 2배, src/theme.ts size.tile)). 칸 (c, r)은 [c, c+1) × [r, r+1)을 차지한다.

| 항목 | 뜻 |
|---|---|
| layout | 한 줄이 한 행, 글자 하나가 한 칸. 글자 뜻은 아래 칸 종류 |
| areas | 장소 목록 `{id, name, col, row, w, h, part?}`. 안내와 CCTV에 지금 장소 이름을 보인다. 네모 밖(문턱)이면 가장 가까운 장소. part 2는 2부 장소 |
| start | 시작 위치(칸 가운데는 .5) |
| objects | 사물 `{id, name, kind, sprite?, col, row, w, h, mission?, part?, flip?}`. 사물은 지나갈 수 없다(연 문만 지나간다) |

- `mission`은 미션 id다. 미션의 종류·문제·정답·단서·아이템·힌트 카드는 서버만 읽는 방탈출 자료 파일(escape/*.yaml)에 있다.
  형식은 escape/example.yaml, 약속은 shared/escape.ts. 선생님이 방마다 자료 파일을 하나 고른다.
- 자료 파일에 미션이 있는 사물만 살펴볼 수 있다(이름표는 mission이 있는 사물에 늘 적는다).
- 문(door, entrance)은 자료 파일에서 open 미션이면 잠겨 있다가 그 학생이 열면 지나갈 수 있고, open 미션이 아니면 처음부터 열려 있다.
  문 밑 칸은 바닥 글자로 둔다.
- 2부(part 2): 선생님이 "2부 열기"를 누르기 전에는 part 2인 문(복도의 2부 문)이 닫혀 있고, part 2인 다른 사물(2부에 새로 놓이는 실험 장치, 전구)은 보이지 않는다.
  2부 장소(part 2인 area) 안의 사물은 2부를 연 뒤에만 살펴볼 수 있다(서버도 막는다). 열면 모두에게 함께 열린다.
- 그림(src/scenes/painter.ts): 사물은 public/sprites/objects/<sprite가 있으면 sprite, 없으면 kind>.png를 차지 칸의 아래에 맞추고 가로 가운데에 놓는다(도트 하나 = 2픽셀).
  열린 모양은 <이름>-open.png(없으면 닫힌 그림을 흐리게), 켜진 모양은 <이름>-on.png(전구: 순서 맞추기에서 바르게 살펴본 것과 마친 미션). flip이면 좌우로 뒤집는다(오른쪽 골대).
  칸은 tiles/<id>.png의 30×30 변형을 칸 자리로 골라 깐다(모든 화면에서 같은 무늬). 그림이 없는 칸·사물은 src/theme.ts의 색 네모로 그린다.
  어떤 그림이 있는지는 빌드할 때 public/sprites를 훑어 정한다(새 그림을 넣으면 화면 개발 서버를 새로 고친다).
- JSON은 `python3 scripts/map-json.py src/data/school.json`으로 읽기 좋은 꼴(한 줄에 사물 하나)로 맞춘다.

## 학교 맵(121 × 37칸, 2026-11-12 계획 배치도대로 넓힘)

```
 [교실]   [과학실]   [컴퓨터실]   | [수학실*]  [도서관*]
 ======== 복도 ================== | ===== 복도(2부)* ====== [계단*]→[옥상 천문대*]
 [            운동장                    [  강당(입구만)  ]          ]
 * 2부(선생님이 "2부 열기"를 누르면 복도의 2부 문이 열린다)
```

| 장소(area id) | 열 | 행 | 바닥 | 문 |
|---|---|---|---|---|
| 교실(classroom) | 1~22 | 2~10 | `.` | 교실 문 21~22열 |
| 과학실(lab) | 24~46 | 2~10 | `:` | 과학실 문 36~37열 |
| 컴퓨터실(computer) | 48~63 | 2~10 | `;` | 컴퓨터실 문 55~56열 |
| 복도(hallway) | 1~64 | 13~16 | `,` | 현관문 23~24열(아래) |
| 2부 문 | 65~66 | 13~16 | `,` | 복도를 가로막는 칸막이 문(partDoor 2×4, part 2) |
| 수학실(math, 2부) | 67~82 | 2~10 | `.` | 수학실 문 74~75열 |
| 도서관(library, 2부) | 84~99 | 2~10 | `_` | 도서관 문 91~92열 |
| 복도(2부)(hallway2) | 67~99 | 13~16 | `,` | |
| 계단(stairs, 2부) | 100~103 | 13~16 | `^` | |
| 옥상 천문대(rooftop, 2부) | 104~119 | 2~16 | `=` | 오른쪽은 난간(`%`) |
| 운동장(field) | 1~64 | 19~35 | `"` | 교문 22~25열(아래 울타리) |
| 강당(들어가지 않음) | 65~120 | 19~36 | `&`(지붕) | 강당 문 65열 26~28행(운동장 쪽 벽, 꾸밈) |

- 0~46열(교실·과학실·1부 복도 왼쪽·운동장 왼쪽)의 좌표는 넓히기 전과 같다.
- landmarks: 미니맵에만 그리는 건물(강당 65~120열·19~36행).
- views: 선생님 CCTV의 구역 보기(1부 건물 0~66열·0~18행, 2부 건물 64~120열·0~18행, 운동장 0~66열·17~36행).

- 아래가 바닥인 가로 벽은 2칸 두께다(윗면 칸 + 앞면 칸). 캐릭터 키가 2칸이라 벽이 1칸이면 벽 앞에 선 캐릭터의 머리가 벽 너머 방까지 올라간다.
  옆 벽(세로)과 운동장 아래 울타리는 1칸이다. 골든벨 맵(19×14칸)도 위쪽 벽이 2칸이다.

예시 자료(escape/example.yaml)의 방탈출 흐름(문제는 모두 예시)
1. 교실: 칠판(단서: 사물함 번호 앞 두 자리) → 교탁(퀴즈, 마치면 번호 뒤 두 자리) → 사물함(숫자 자물쇠 3141) → 교실 문 열쇠 → 교실 문(퀴즈)을 열고 복도로
2. 복도: 게시판(단서) → 신발장(단답형) → 과학실 열쇠 → 과학실 문을 열고 과학실로. 바닥의 흙 습도 센서·물 펌프(줍기)
3. 과학실: 약품장(단서) → 실험대(반 자물쇠: 수과학반은 파동, AI.SW반은 2진수 문제),
   얼음 비커 → 물 비커 → 수증기 플라스크(순서 맞추기) → 현관 열쇠, 스마트 화분 실험대(부품 두 개 가져다주기) → 복도로 나와 현관문을 열고 운동장으로
4. 운동장: 교문(퀴즈)을 열면 탈출
- 힌트 카드: 교탁, 신발장, 실험대(반 자물쇠), 스마트 화분 실험대(가져다주기)에서 한 장씩(4장)

## 화면(카메라)
- 학교 맵: 내 아바타를 따라간다. 화면 짧은 쪽에 대략 size.viewTiles(15)칸이 보이는 배율에 가장 가까운, 캔버스 픽셀 기준 1/size.zoomSnap(2) 단위로 맞춘다
  (0.5, 1, 1.5: 도트 2배 그림의 도트 하나가 캔버스 픽셀 정수). 맵 밖은 비추지 않는다.
- 그리는 방식(src/render.ts, 주소 끝 ?render=): 기본은 css(교사 결정, 화면 픽셀로 그리고 0.5 단위로 맞춤). dpr은 캔버스를 기기 픽셀(devicePixelRatio) 해상도로 그린다(레티나 화면이면 화면 배율 0.25 단위).
  캔버스가 긴 쪽 size.canvasMaxLong(2732)·짧은 쪽 canvasMaxShort(2048)를 넘으면 그 안에 들도록 비율을 낮추고, 배율은 그 캔버스 픽셀 단위로 맞춘다.
  free는 화면(CSS) 픽셀로 그리고 배율을 단위에 맞추지 않는다. css는 화면 픽셀로 그리고 화면 배율 0.5 단위로 맞춘다(전의 방식).
  ?fps=1이면 왼쪽 아래에 방식, 캔버스 비율·크기, 배율, 캐릭터 키, fps를 띄운다(교사가 기기에서 견줘 보려고 둠).
