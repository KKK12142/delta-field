# Delta Field 맵

맵 데이터의 형식과, 그림 담당이 그릴 바닥·벽·사물 종류를 적는다. 그림 규격(도트 16개 = 1칸, 3배)은 docs/art.md에 있다.

## 맵 파일
- src/data/school.json: 교실·복도·실험실·운동장이 이어진 학교 맵(id `school`). 방탈출을 한다.
- src/data/goldenbell.json: 골든벨 맵(id `goldenbell`).
- 형식은 src/data/room.ts에 있다. 좌표는 모두 칸 단위(한 칸 = 화면 48px). 칸 (c, r)은 [c, c+1) × [r, r+1)을 차지한다.

| 항목 | 뜻 |
|---|---|
| layout | 한 줄이 한 행, 글자 하나가 한 칸. 글자 뜻은 아래 칸 종류 |
| areas | 장소 목록 `{id, name, col, row, w, h}`. 안내와 CCTV에 지금 장소 이름을 보인다. 네모 밖(문턱)이면 가장 가까운 장소 |
| start | 시작 위치(칸 가운데는 .5) |
| items | 아이템 id → 이름 |
| objects | 사물 `{id, name, kind, col, row, w, h, action?, requires?, lockedText?, doneText?}`. 사물은 지나갈 수 없다(연 문만 지나간다) |
| quizzes | 퀴즈 `{example?, question, choices, answer}`. answer는 0부터 |

action 종류
- `clue`: 글을 보인다(`gives`가 있으면 아이템을 준다).
- `quiz`: 퀴즈를 맞히면 아이템(`gives`)을 준다.
- `open`: 문. (`quiz`가 있으면 맞힌 뒤) 열리고, 연 학생만 지나갈 수 있다. 문 밑 칸은 바닥 글자로 둔다.
- `exit`: 출구. (`quiz`가 있으면 맞힌 뒤) 탈출한다.
- `requires`가 있으면 그 아이템이 있어야 action을 한다(없으면 `lockedText`).

## 학교 맵(48 × 37칸)

```
 0 ################################################   맨 위 벽 2칸(0행 윗면, 1행 앞면: 칠판)
 1 ################################################
 2 #......................#:::::::::::::::::::::::#   위 왼쪽: 교실(22×9), 위 오른쪽: 실험실(23×9)
 …
11 #####################,,#############,,##########   벽 2칸(12행이 복도 쪽 앞면: 게시판). 교실 문(21~22열), 실험실 문(36~37열)은 2×2
12 #####################,,#############,,##########
13 #,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,,#   복도(46×4)
 …
17 #######################,,#######################   벽 2칸(18행이 운동장 쪽 앞면). 현관문(23~24열)은 2×2
18 #######################,,#######################
19 %""""""""""""""""""""""""""""""""""""""""""""""%   운동장(46×17)
 …
36 %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%   교문(22~25열)
```

- 아래가 바닥인 가로 벽은 2칸 두께다(윗면 칸 + 앞면 칸). 캐릭터 키가 2.5칸이라 벽이 1칸이면 벽 앞에 선 캐릭터의 머리가 벽 너머 방까지 올라간다.
  옆 벽(세로)과 운동장 아래 울타리는 1칸이다. 골든벨 맵(19×14칸)도 위쪽 벽이 2칸이다.

방탈출 흐름(퀴즈는 모두 예시 문제)
1. 교실: 칠판(단서) → 교탁(퀴즈) → 사물함 열쇠 → 사물함(퀴즈) → 교실 문 열쇠 → 교실 문(퀴즈)을 열고 복도로
2. 복도: 게시판(단서) → 신발장(퀴즈) → 실험실 열쇠 → 실험실 문을 열고 실험실로
3. 실험실: 약품장(단서) → 실험대(퀴즈) → 현관 열쇠 → 복도로 나와 현관문을 열고 운동장으로
4. 운동장: 교문(퀴즈)을 열면 탈출

## 그릴 것 목록

### 칸(타일)
| 글자 | id | 이름 | 종류 | 쓰는 곳 |
|---|---|---|---|---|
| `.` | classroomFloor | 교실 바닥(나무) | 바닥 | 교실, 골든벨 맵 |
| `,` | hallFloor | 복도 바닥 | 바닥 | 복도, 문·현관문 밑 |
| `:` | labFloor | 실험실 바닥(타일) | 바닥 | 실험실 |
| `"` | field | 운동장 흙 | 바닥 | 운동장 |
| `#` | wall | 건물 벽 | 벽 | 건물 둘레, 방 사이 |
| `%` | fence | 울타리 | 벽 | 운동장 둘레 |

- 벽은 윗면과 앞면 두 가지를 그린다. 아래 칸이 바닥인 벽 칸이 앞면이다(그 칸을 통째로 앞면 그림으로 덮을 수 있게 그리기 코드를 나눠 두었다: src/scenes/painter.ts의 wall()).
- 바닥은 변형 2~4개를 이어 한 장으로(docs/art.md).

- 살펴볼 수 있는 사물에는 지금 이름표를 글자로 띄운다. 그림이 들어와도 이름표는 남긴다(무엇을 살펴볼지 알게).

## 화면(카메라)
- 학교 맵: 내 아바타를 따라간다. 화면 짧은 쪽에 대략 size.viewTiles(12)칸이 보이는 배율에 가장 가까운 1/size.zoomSnap(2) 단위로 맞춘다(1, 1.5, 2: 도트 2배 그림의 도트 하나가 정수 픽셀). 맵 밖은 비추지 않는다.
- 골든벨 맵: 맵 전체를 화면에 맞춘다.
- 선생님 CCTV 전체 보기: 학교 맵 전체를 맞춘다(확대는 정수 단위가 아님). 학생을 고르면 그 학생을 내 화면과 같은 배율로 따라간다.
- 그리기는 src/scenes/painter.ts 한곳에 있다: ground()(바닥·벽을 한 장으로 구움), floor(), wall(), object(). 캐릭터 아바타는 src/scenes/avatar.ts.
